Richtig oder Falsch? Geben Sie eine kurze Begründung oder ein Gegenbeispiel an. Für alle Fragen gilt: das Vektorfeld ist ein 3D-Vektorfeld das überall definiert (und stetig differenzierbar) ist.

- Der Fluss eines wirbelfreien Feldes durch eine geschlossene Oberfläche ist immer Null.

- Wenn die Divergenz eines Vektorfeldes überall Null ist (quellenfrei), dann ist der Fluss durch jede geschlossene Oberfläche Null.

- Der Satz von Stokes besagt, dass das Integral der Rotation rot$\vec{v}$ über eine geschlossene Fläche (wie eine Kugeloberfläche) immer Null ist.

- Die Durchlaufrichtung einer Randkurve beim Satz von Stokes ist beliebig, solange man den Normalvektor auf die Fläche passend wählt.

- Wenn zwei verschiedene Flächen $S_1$ und $S_2$ dieselbe Randkurve $\partial S$ besitzen (in dieselbe Richtung durchlaufen), dann ist das Integral der Rotation rot$\vec{v}$ über beide Flächen identisch.
