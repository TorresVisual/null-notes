11. Übungsblatt

1. Berechnen Sie mithilfe des Residuensatzes das komplexe Kurvenintegral

    $
    \oint_C \frac{z^2 + 5}{z^2 - 3z + 2} dz
    $

    für die folgenden Fälle (die Kurve wird jeweils einmal mathematisch positiv durchlaufen):

    1. $C$ ist der Kreis mit Radius $R = \frac{1}{2}$ um den Mittelpunkt $z_0 = 1.$

    2. $C$ ist der Kreis mit Radius $R = \frac{1}{2}$ um den Mittelpunkt $z_0 = 2.$

    3. $C$ ist der Kreis mit Radius $R = 3$ um den Ursprung.

2. Berechnen Sie mithilfe des Residuensatzes das komplexe Kurvenintegral

$
\oint_C \frac{e^{2z}}{(z - 1)^2 \cdot z} dz
$

wobei $C$ der einmal mathematisch positiv durchlaufene Kreis mit Radius $R = 2$ um den Ursprung ist.

3. Gegeben ist die komplexe Funktion

$
f(z) = \frac{2z + 1}{z^3 - z^2 - z + 1} . \oint_C
$

Berechnen Sie das Kurvenintegral $f(z)dz$ entlang des einmal mathematisch positiv durchlaufenen Kreises $C$ mit Radius $R = 3$ um den Ursprung. Hinweis: Der Nenner besitzt die Nullstelle $z_1 = 1.$

4. Berechnen Sie mithilfe des Residuensatzes das komplexe Kurvenintegral

$
\oint_C \frac{\cos(z)}{z^3} \text{+} \frac{4z}{2z^2 - 2z + 1} \text{+} \frac{1}{z^4} dz,
$

wobei $C$ der einmal mathematisch positiv durchlaufene Kreis mit Radius $R = 1$ um den Ursprung ist.

5. Berechnen Sie mithilfe des Residuensatzes das komplexe Kurvenintegral

$
\oint_C \frac{1}{z^2 + 4} \text{+} \frac{1}{((2z - 2)^2 + 1)^2} dz,
$

wobei $C$ das einmal mathematisch positiv durchlaufene Dreieck in der komplexen Zahlenebene mit den Eckpunkten $A = -1 - i, B = 2 - i$ und $C = i$ ist.

6. Gegeben ist das reelle Vektorfeld

    $
    \vec{v}(x, y) = \begin{pmatrix} 3x^2 - 3y^2 + 2x + 2y \\ -6xy + 2x - 2y \end{pmatrix}.
    $

    Bestimmen Sie das reelle Potenzial $\Phi(x, y)$ dieses Feldes mithilfe komplexer Analysis:

    1. Ordnen Sie dem Vektorfeld die entsprechende komplexe Feldfunktion$f(z) = P(x, y)-$ $i \cdot Q(x, y)$ zu und drücken Sie diese vollständig als Funktion von $z = x + iy$ aus.

    2. Bestimmen Sie die komplexe Stammfunktion $F(z)$ von $f(z).$

    3. Ermitteln Sie das reelle Potenzial $\Phi(x, y),$ indem Sie den Realteil der komplexen Stammfunktion $F(z)$ berechnen.

Richtig oder Falsch? Geben Sie eine kurze Begründung oder ein Gegenbeispiel an. Alle Fragen beziehen sich auf Funktionen und Kurvenintegrale in der komplexen Zahlenebene $\mathbb{C}.$

- Das Residuum einer Funktion an einer isolierten Singularität ist immer ungleich Null.

- Wenn eine Funktion $f$ im Inneren einer geschlossenen Kurve $C$ nur Pole der Ordnung $\geq 2$

$
\oint_C
$

besitzt, dann ist das Kurvenintegral $f(z)dz$ immer gleich Null.

- Sei $f$ holomorph auf einem Gebiet außer an endlich vielen isolierten Singularitäten. Umschließt eine geschlossene Kurve $C$ keine dieser Singularitäten, so ist das Integral

$
\oint_C f(z)dz = 0.
$

- Das Residuum einer Linearkombination zweier Funktionen ist gleich der Linearkombination ihrer einzelnen Residuen, d.h. Res$(\alpha f + \beta g, z_0) = \alpha$Res$(f, z_0) + \beta$Res$(g, z_0).$
