Richtig oder Falsch? Geben Sie eine kurze Begründung oder ein Gegenbeispiel an. Alle Fragen beziehen sich auf lineare Differentialgleichungen mit konstanten Koeffizienten.

- Die allgemeine Lösung einer homogenen linearen Differentialgleichung $n-$ter Ordnung bildet immer einen $n-$dimensionalen Vektorraum.

- Die allgemeine Lösung einer inhomogenen linearen Differentialgleichung $n-$ter Ordnung bildet immer einen $n-$dimensionalen Vektorraum.

- Liegt ein Resonanzfall vor, so besitzt die inhomogene Differentialgleichung keine partikuläre Lösung mehr.

1

- Der Superpositionsansatz besagt beispielsweise, dass man bei einer Störfunktion der Form $4x+e^{2x}$ die partikulären Lösungen für $4x$ und $e^{2x}$ getrennt berechnen und danach addieren darf.

- Um eine eindeutige Lösung für eine lineare Differentialgleichung $n-$ter Ordnung zu erhalten, benötigt man genau $n$ Anfangswerte.

- Wenn alle Anfangswerte für eine lineare Differentialgleichung $n-$ter Ordnung gleich Null sind, dann ist die Lösungsfunktion die konstante Nullfunktion (also $y(x) = 0$ für alle $x).$
