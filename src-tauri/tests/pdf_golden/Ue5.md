Beispiel 5.1. Bestimmen Sie für die folgenden simultanen Kongruenzen jeweils alle Lösungen oder begründen Sie, warum es keine Lösungen gibt. Falls es Lösungen gibt, ermitteln Sie auch die kleinste positive Lösung.

| (a) | $x \equiv 3$ mod 7 |  (b) | $x \equiv 11$ mod 15 |
| --- | --- | --- | --- |
|  | $x \equiv 1$ mod 9 |  | $x \equiv 5$ mod 21 |
|  | $x \equiv 4$ mod 13 |  | $x \equiv 26$ mod 105 |

Beispiel 5.2. Ermitteln Sie für die folgenden simultanen Kongruenzen jeweils alle Lösungen oder begründen Sie, warum es keine Lösungen gibt. Falls es Lösungen gibt, ermitteln Sie auch die kleinste positive Lösung.

| (a) | $x \equiv 21$ mod 63 |  (b) | $x \equiv 16$ mod 63 |
| --- | --- | --- | --- |
|  | $x \equiv 42$ mod 91 |  | $x \equiv 2$ mod 91 |
|  | $x \equiv 16$ mod 117 |  | $x \equiv 106$ mod 117 |

*Hinweis.* Finden Sie zuerst Zahlen $m_1, m_2, m_3,$ die relativ prim sind (also ggT$(m_i, m_j) = 1$ wann immer $i ̸= j)$ und $63 = m_1m_2, 91 = m_1m_3$ und $117 = m_2m_3$ erfüllen. Übersetzen Sie dann, falls möglich, die Kongruenzen aus der Aufgabe in die Form

$
x \equiv c_1 \text{ mod } m_1
$

$
x \equiv c_2 \text{ mod } m_2
$

$
x \equiv c_3 \text{ mod } m_3
$

und lösen Sie diese mit Hilfe des chinesischen Restsatzes.

Beispiel 5.3. Mit welchen der folgenden Verknüpfungen $\circ$ bildet $(\mathbb{Z},\circ)$ eine Halbgruppe, ein Monoid oder sogar eine Gruppe? Gilt das Kommutativgesetz? Begründen Sie die jeweiligen Eigenschaften oder geben Sie Gegenbeispiele an.

1. $x \circ y = xy - 2$

2. $x \circ y = x + y - 2$

Beispiel 5.4. Wir betrachten die Menge $X$ aller Teilmengen von $\mathbb{R}.$ Mit welchen der folgenden Verknüpfungen $\circ$ bildet $(X,\circ)$ eine Halbgruppe, ein Monoid oder sogar eine Gruppe? Gilt das Kommutativgesetz? Begründen Sie die jeweiligen Eigenschaften oder geben Sie Gegenbeispiele an.

3. $A \circ B = A\triangle B$

4. $A \circ B = A \cup B$

mit Hilfe der Primfaktorzerlegungen. Rechnen Sie dabei auch vor, wie Sie die Primfaktorzerlegungen erhalten haben.
