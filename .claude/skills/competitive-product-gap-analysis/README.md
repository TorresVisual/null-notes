# Competitive Product & Feature Gap Analysis Skill

A reusable agent skill for evidence-driven competitor research, feature-gap discovery, and prioritized product recommendations.

## Contents

- `SKILL.md` — skill instructions and workflow
- `templates/report-template.md` — default report structure

## Use

Provide the target application's name and, where possible, its official website, repository, and any product constraints. The skill establishes a verified feature baseline before researching competitors, distinguishes unknown from absent functionality, and prioritizes concrete opportunities.
