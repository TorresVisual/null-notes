# Wiki-links can't carry display text or point at a heading

## Summary
Support `[[Note|shown text]]` and `[[Note#Heading]]` (and the two combined), with navigation that scrolls to the heading.

## Problem
A link to "the Master theorem section of Recurrences" can only point at the whole note, and a link cannot read naturally in a sentence. Typing `[[Note|text]]` today creates an unresolved link to a note literally named "Note|text".

## Competitor reference
[Internal links](https://obsidian.md/help/links) document `[[Note|Custom name]]` for display text and `[[Note#Heading]]` for anchor links.

## Current behavior
`src/editor/extensions/WikiLink.tsx:251-273` serialises `[[${title}]]` and parses with `/\[\[([^\]\n]+)\]\]/`; the node has a single `title` attribute. `notes.rs` `extract_links` (:113) and the `note_links.target_title` column are keyed by title only. Cross-references (`CrossRef.ts`) cover callouts and equations, not headings.

## Expected behavior
A link can show custom text and/or target a heading; clicking opens the note and scrolls to the heading; hover preview, backlinks and rename keep working.

## Acceptance criteria
- [ ] `[[Note|text]]` renders `text`, resolves to Note, and round-trips unchanged
- [ ] `[[Note#Heading]]` resolves to Note and scrolls to that heading on click (case-insensitive match; missing heading falls back to the note top)
- [ ] `[[Note#Heading|text]]` works
- [ ] The `[[` autocomplete offers headings after `#`
- [ ] Backlinks and the graph treat all forms as links to Note (anchor and display text stripped for `target_title`)
- [ ] Renaming a note preserves the `#...` and `|...` parts of every link to it
- [ ] Unit tests for parse/serialize and `extract_links`

## Scope
**In:** Display text and heading anchors on wiki-links.

**Out (track separately):** Block references (`#^id`) and embeds (D05); heading-rename link repair.

## Implementation considerations
Add `heading` and `label` attributes next to `title` in `WikiLink.tsx`; scrolling can reuse `lib/pendingHighlight.ts` / `SearchJumpHighlight.ts`. `rename_note_at` rewrites links today and must keep the suffixes. Interacts with same-title collisions (#122): resolve the note first, then the heading.

## Priority
P2. Heading targets and custom link text are the two most-used link forms after the plain title; without them a long note can only be linked as a whole.
