# Fold headings and lists in long notes

## Summary
Add fold/unfold controls for headings and list items, plus "Fold all" / "Unfold all" commands.

## Problem
Revision notes get long. The student can only scroll, use the Outline, or wrap content in a manual collapsible block.

## Competitor reference
[Folding](https://obsidian.md/help/folding) lets users collapse headings and lists, with commands to fold and unfold everything.

## Current behavior
Only the explicit collapsible block (`extensions/Details.tsx`) and code-block folding exist. There is no heading or list folding; the Outline click scrolls only.

## Expected behavior
A chevron on headings and list items folds the content beneath; fold state is view-only and never changes the `.md` file.

## Acceptance criteria
- [ ] Hover chevron on headings and list items folds/unfolds their section
- [ ] "Fold all headings and lists" / "Unfold all" in the command palette
- [ ] Folded content is skipped by arrow-key navigation but included in find/replace, which unfolds on a match
- [ ] Outline click and wiki-link jumps unfold the target
- [ ] Fold state is not written to the note; optional per-session persistence in UI state
- [ ] Focus mode (Ctrl+Shift+F) keeps working

## Scope
**In:** Heading and list folding.

**Out (track separately):** Persisting fold state in the Markdown file.

## Implementation considerations
Implement as a ProseMirror plugin with decorations so the document content is untouched; mind `FindReplace.ts`, `FocusMode.ts` and `OutlinePanel`. UI state stays out of the `.md` (CLAUDE.md storage boundary).

## Priority
P3. Navigation aid for long notes; the Outline panel and collapsible blocks cover part of the need.
