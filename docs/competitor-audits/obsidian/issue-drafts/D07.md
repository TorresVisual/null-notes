# Tabs: pin a tab and jump to a tab by number

## Summary
Add Pin/Unpin for tabs (pinned tabs stay put and keep their note) and Ctrl+1..8 / Ctrl+9 shortcuts for the nth and last tab.

## Problem
With many tabs open the only ways to move are Ctrl+Tab cycling or the mouse, and a reference note (a formula sheet, a task list) is replaced as soon as a link is followed in its tab.

## Competitor reference
[Tabs](https://obsidian.md/help/tabs) describe pinning (links in a pinned tab open elsewhere) and Ctrl+1..9 jumps.

## Current behavior
`TabBar.tsx` supports drag-reorder only; `Layout.tsx:502-526` `KEY_COMMANDS` has no digit keys; `store/workspace.ts` holds `openTabs` with no pinned flag and `commands/workspace.rs` persists `openTabs`/`activeTab`.

## Expected behavior
Pinned tabs are shown compactly at the left, survive restart, and a link followed inside one opens in a new tab; Ctrl+1..9 switch tabs.

## Acceptance criteria
- [ ] Tab context action and palette entry Pin/Unpin
- [ ] Pinned tabs sort before unpinned ones, show a pin glyph and survive relaunch
- [ ] Following a wiki-link inside a pinned tab opens a new tab
- [ ] Ctrl+1..8 select tabs 1..8 and Ctrl+9 the last tab; the shortcut sheet and palette list them
- [ ] Closing a pinned tab asks for confirmation (or needs unpin first)

## Scope
**In:** Pinning and numeric tab shortcuts.

**Out (track separately):** Stacked tab groups, pop-out windows, named layouts.

## Implementation considerations
Pinned state is UI state: it belongs in `.workspace.json` (inside the workspace, gitignored) via `WorkspaceState` in `commands/workspace.rs`. Digit keys need a branch in `Layout.tsx` because the map is keyed by single characters. Align with D09 if shortcuts become configurable.

## Priority
P3. Small ergonomics gain for people who keep a reference note open while working through others.
