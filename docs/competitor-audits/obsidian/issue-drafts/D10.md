# One command to open or create today's dated note

## Summary
A command (and palette/menu entry) that opens the note for today's date, creating it from a chosen template if it does not exist.

## Problem
Keeping a per-day lecture or lab log means creating a note, typing the date, and applying a template by hand every time.

## Competitor reference
[Daily notes](https://obsidian.md/help/plugins/daily-notes) opens today's note or creates it from a template, with configurable folder, date format and template; [Unique note creator](https://obsidian.md/help/plugins/unique-note) creates timestamp-named notes.

## Current behavior
No daily-note code. `useCreateNoteFromTemplate.ts` and `lib/templatePlaceholders.ts` already substitute a `{{date}}` field; `TemplateDialog.tsx` pre-fills today's date but always asks the user to pick a template and name.

## Expected behavior
Run "Open today's note": if `<folder>/<date>.md` exists open it, otherwise create it from the configured template and open it.

## Acceptance criteria
- [ ] Command in the palette and File menu; optional shortcut
- [ ] Settings: target folder, date format (default YYYY-MM-DD), optional template
- [ ] Existing note for the date is opened, not duplicated
- [ ] Works in a NotesMonorepo workspace (folder is per workspace)
- [ ] Created file goes through the normal create path (write_atomic, index)

## Scope
**In:** Today's-note command.

**Out (track separately):** Calendar view, weekly/monthly notes, timestamp-named unique notes.

## Implementation considerations
Where the setting lives is a storage-boundary decision: a template/folder choice that should travel with the notes belongs in the workspace, a personal preference in `settings.json`; record it per `docs/ROADMAP.md` §1.

## Priority
P3. Convenience for lecture/lab logs; templates already cover the content, so only the dated entry point is missing.

## Category
Core Editing (note creation)
